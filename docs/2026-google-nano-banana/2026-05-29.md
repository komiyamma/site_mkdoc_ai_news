**過去24時間（2026年5月28-29日頃）のGoogle「Nano Banana」関連の主な情報は、Nano Banana 2とNano Banana Proの**一般公開（GA）**です。**

### 公式発表の概要
- **Nano Banana 2**（Gemini 3.1 Flash Imageベース）：速度・コスト効率を重視した高ボリューム向けモデル。高速生成・編集に最適。
- **Nano Banana Pro**（Gemini 3 Pro Imageベース）：プロ級の精度・クリエイティブ制御を重視したモデル。複雑なワークフロー向け。

**Gemini API、Google AI Studio、Gemini Enterprise Agent Platform**で利用可能になり、開発者・企業向けに本番環境で安定して使用できます。Nano Banana 2はビデオファイル入力（プレビュー）も新たにサポートし、動画の文脈理解に基づく画像生成（サムネイルなど）が可能。

**強み**（公式リフレッシャー）：
- 被写体の一貫性（最大5キャラクター維持）
- 正確なテキストレンダリング・多言語対応
- 4Kアップスケール・カスタムアスペクト比
- 最大14枚の参照画像入力
- Google検索 grounding による事実性向上

**[@googledevs](https://x.com/googledevs/status/2060029439212466189)** が詳細スレッドを投稿。  
**[@Google](https://x.com/Google/status/2060029132105191723)** もGAを告知。

**[@GoogleCloudTech](https://x.com/GoogleCloudTech/status/2060033890119475653)**（Thomas Kurian氏関連）では、Enterprise Agent Platform経由のGAとビデオ入力新機能を強調。企業アプリケーションへの統合をアピール。
