**過去1週間（2026年5月17日〜24日頃）のAIコーディングツール（Claude Code、Codex、Cursor、Geminiなど）の「Skills」関連情報まとめ。**

Skillsは、主に`SKILL.md`ファイル（または同等の形式）で定義される再利用可能なワークフロー/手順で、Claude Codeを中心にCodex、Cursor、Gemini CLIなどクロスプラットフォームで動作するオープン標準です。繰り返しのタスク（コードレビュー、セキュリティスキャン、計画立案など）を自動化・標準化し、コンテキストを効率的に管理します。過去1週間は新Skillの共有、GitHubリポジトリの更新、ユーザー体験談が活発でした。古い情報は除外しています。

### 1. Claude Code / CodexのSkills活用事例（X上の最近の発言）
- **SkillForgeの日常更新**：SkillForgeで毎日新Skillが追加。5月24日時点で17個追加され、累計6,155個超。注目例として`career-ops`（求職支援：職種評価・履歴書生成・スキャン）、`ai-legal-claude`（法律業務：契約審査・リスク分析・NDA生成、14スキル+5並行エージェント）、`claude-seo`（SEO分析、25サブスキル）、`nextjs-cache-architecture`（Next.jsキャッシュ設計）など。データ/AI開発ツール分野が活発。

- **繰り返し作業のSkill化Tips**（@reach_vb氏共有、広く引用）：Codex/Claude Codeの過去セッションを分析し、繰り返し作業をSkillやsubagentに変換するプロンプト例。「CI失敗、PRレビュー、changelog、docs更新、debug、test triage」などを対象にシンプルに作成。多くのユーザーが実践中。

- **セキュリティSkill**：コードを深くスキャンし20以上の一般的な脆弱性を検出するClaude Code Skill。DevSecOps向けで、安全なコード出荷を加速。

- **Apple開発向けSkills**：iOS 26、SwiftUI、Liquid Glass対応の`apple-skills`。Claude Code/Codexで利用可能。

- **PaperSpine Skill**：論文/レポート執筆向け。動機付けワークフロー、既存原稿rewrite/新規作成対応。Codex（単一Skillバンドル）・Claude Code（slashコマンド）両対応。理由記録・監査機能付き。

- **その他ユーザー声**：Cursor CLIがClaude Skillsを自動認識して高速動作（@0xdef1cafe氏）。Claude Code + Codexの2窓運用で$と/の入力ミス注意（@tsonobe_氏）。SkillCreatorのようなメタSkillで自作を容易化する流れも継続。
