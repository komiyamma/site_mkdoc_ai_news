**過去1週間（2026年6月1日〜7日頃）のAIコーディングツール（Copilot、Gemini、Codexなど）における「Skills」（Agent Skills）の主な話題を、X上の発言とインターネット情報からまとめました。**

Agent Skillsは、AIエージェントに専門的なワークフロー・指示・ドメイン知識をモジュール化して提供する仕組みで、SKILL.mdファイルなどを用いたオープン標準的なアプローチです。プロンプトの肥大化を防ぎ、コンテキストを必要時のみロードする「progressive disclosure」が特徴。Claude Code、Cursor、Copilot、Gemini CLI、Codexなどでクロスプラットフォーム対応が進んでいます。

### Google公式のAgent Skillsリポジトリリリース
Googleが**google/skills**リポジトリを公開（Apache-2.0ライセンス、★11.4k）。Google Cloud製品（BigQuery、Firebase、GKEなど）向けの13個のSkillsを提供。Claude Code、Cursor、Copilotなどのエージェントで動作し、npx skills add google/skillsなどでインストール可能。エージェントの標準化、プロンプト削減、精度向上に寄与すると話題に。

**[@JayTL00](https://x.com/JayTL00/status/2063496284057849991)** がソースリンクとともに紹介。

### Codex向けSkillsの更新（codex-dev-skills v0.2.0）
**[@jeffery777yang](https://x.com/jeffery777yang/status/2063496850469277811)** がリリースを報告。Codex CLI/Desktop向けのワークフローパックとして進化：
- Desktop wrapper V1（bounded helper path）
- Thread delegation / handoff
- Formal review gates
- Merge readiness
- Security scan before release

デモ動画付きで、単なるスキル集から明確なワークフロー中心へ移行した点が強調されています。

### GitHub Copilot関連のSkills/Agentic強化
- Copilot CLIやJetBrains IDEでAgentic機能強化（agent picker、slash commands、Agent Debug panelなど）。Geminiモデル（3.1 Pro Preview、3.5 Flash）対応も拡大。
- Copilot Studioの新designer（早期アクセス）で**Skills**が第一級機能として登場。Microsoft IQ、Tools、Knowledge、Connected agentsと連携し、構造化されたエージェントアーキテクチャへ移行中。
- VS Codeでのremote/resumable agent sessions（SSH経由）など、Skillsを活かしたワークフローが進展。

**[@DanKornas](https://x.com/DanKornas/status/2063244741798494710)** は「Agent Skills」コレクションを紹介。再利用可能な指示セット（engineering、devrel、marketingなど）で、Claude Code/Gemini CLI/Cursor/Copilot/Codex対応。atomic設計、SKILL.md起点のprogressive disclosure、評価ノート付きのオープンソース（MIT）。
