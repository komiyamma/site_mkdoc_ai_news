**ここ一週間（特に直近3日程度）のMCP (Model Context Protocol) 関連ニュースまとめ**（2026年5月17日以降中心、5月21日頃〜24日重点）。

MCPはAnthropicが2024年に提唱したオープン標準プロトコルで、AIモデル（LLM）が外部ツール・データソース・リソースに標準化された方法で接続するための「AI版USB-C」のようなものです。クライアント-サーバーアーキテクチャ（Host → Client → Server → Tool）で、JSON-RPCなどを用い、ツール呼び出しのポータビリティを高めています。最近は**ステートレス化**、**MCP Apps（サーバー側レンダリングUI）**、**セキュリティ強化（OAuthなど）**が進み、生産性・スケーラビリティ向上が話題です。

### 主な最近の動き（X/Twitter上）
- **AWS MCP ServerのGA影響継続**：AWSがMCPサーバーを一般提供し、15,000+のAWS APIを単一ツール（call_aws）で露出。IAM認証活用でスキーマ散逸を防ぐ点が評価され、企業採用加速の象徴に。
- **ステートレスRCリリース関連**：MCPの新リリース候補が完全ステートレス化され、ロードバランサー後段でのスケール容易化、MCP Apps追加、OAuth強化、ツールスキーマ改善。Microsoft Copilotでのテスト言及もあり、生成UIやエージェント適合が議論。10週間フィードバック期間中。
- **実装・ユースケース議論**：OpenPencil（MITオープンソースAIネイティブベクター設計ツール）が組み込みMCPサーバー搭載で注目。canvas-native vs MCPサーバーの文脈ハンドオフ比較、kubesharkのネットワーク可視化MCP活用、Home Assistant MCPサーバー更新など実践例増加。
- **セキュリティ・運用**：リモートMCPサーバーの認証セキュリティ測定研究（arxiv）、JWT認証付き生産グレードMCPサーバー構築、権限制御議論。
