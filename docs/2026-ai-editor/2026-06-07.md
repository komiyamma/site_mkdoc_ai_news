**VSCode（Visual Studio Code）**  
ここ1週間では、**VS Code 1.123**（6月3日リリース）が主なトピックです。エージェント機能の強化（Dev Tunnels、Agentsウィンドウの改善）、統合ブラウザの更新、1Mコンテキストウィンドウ対応などが追加され、AIエージェント中心の開発ワークフローをさらに推進しています。Microsoft Build 2026関連のライブストリームやデモも活発で、Rubber Duck DebuggingやCopilot CLIの活用例が共有されました。

公式アカウント**[@code](https://x.com/code)**からは、Dev Tunnelsのデモやライブイベント告知が複数ありました（例: [Dev Tunnels関連投稿](https://x.com/code/status/2062652621165400545)）。他の指定アカウントでは目立った最近の発言は確認されませんでした（分散引用を守り、無関係なものはスルー）。一般ユーザー間では安定した日常ツールとしての言及が多く、Copilotとの組み合わせが好評です。

**Cursorエディター**

公式**[@cursor_ai](https://x.com/cursor_ai)**がDesign Modeの動画を投稿（例: [Design Mode発表](https://x.com/cursor_ai/status/2062950344687272144)）。ユーザー側では「VS Code + 拡張機能で代用可能」「複雑なリファクタリングに強い」などの実践声が分散して見られ、@ringoさんなどはCodex + Cursor Composerの組み合わせで高速化を報告。@mckaywrigley、@leerobなどの指定アカウントからも最近の関連言及が確認できました（3つ以内に抑え分散）。

**Antigravity（IDE）**  
出たばかりの新しさゆえ情報は流動的ですが、**Antigravity 2.0**（Google I/O 2026で発表・アップデート強制適用）の影響が強く残っています。VS Codeフォークからエージェント中心の「コントロールタワー」型に大幅シフトし、IDE部分が簡素化・CLI統合が進んだことで「エディタが消えた」「クォータ制限が変わった」などのユーザー混乱・不満の声が目立ちます。一方で、フロントエンド構築の速さとClaude Codeとの並行利用で「スピードと精度が良い」との肯定的意見も。

最近のX投稿では@41_ksnzさん「フロントエンドはAntiGravityが早くて綺麗」、@otokuninaritaiさん「アップデートでIDEが変わってややこしい」などの実体験共有が見られました。大型ニュースサイト中心に集めたところ、Gemini CLI移行やエージェント機能強化が主眼です。

**Visual Studio（IDE）**  
Visual Studio 2026の**May Update（18.6.x）**関連のフォローアップが続いています。システムテーマ自動切替、Copilot拡張機能の強化、C++現代化エージェントなどがハイライト。AIネイティブIDEとしての位置づけが強調され、.NET/C++開発者向けの安定したアップデートが進行中です。

公式**[@VisualStudio](https://x.com/VisualStudio)**はAIに関する啓発動画やデバッグTips、退職者送別などを投稿（例: [AI関連](https://x.com/VisualStudio/status/2063275116499234863)）。@kkamegawaさんはCopilot ExtensionのVS版新機能公開を報告。他の指定アカウント（@davidfowlなど）からも最近の関連言及がありましたが、分散してピックアップ。VS Codeとは区別し、フルIDEとしての堅牢さが再確認される1週間でした。
