### Anthropic/Claudeの躍進
Anthropicが**9650億ドル**規模の評価額で巨額資金調達を実施し、OpenAIを上回る世界最大のプライベートAI企業となりました。さらに**IPO（新規株式公開）**に向けた機密書類をSECに提出。Claudeの企業向け採用が強く、評価額急上昇の要因です。

- [@claudeai](https://x.com/claudeai) 関連の動きとして、Snowflake Summitでのパートナーシップ強化（Claude in Cortex AI）が注目されています。

この動きはAI業界の資金調達・上場競争を加速させるでしょう。

### OpenAI / ChatGPT
**OpenAIのフロンティアモデルとCodex**がAmazon Bedrockで一般提供開始。企業はAWSのセキュリティ・ガバナンスを活用しやすくなりました。GPT-5.5 / GPT-5.4モデルも利用可能で、コーディングエージェントとしてのCodexが特に企業向けに強化されています。

ChatGPTでは**求人検索とレジュメ作成機能**が新たに追加され、就職支援が強化されました。

[@OpenAIDevs](https://x.com/OpenAIDevs/status/2061564710173224985)の投稿でも、AWS統合を積極的にアピールしています。

### Microsoft / GitHub Copilot
GitHub Copilotの請求体系が**使用量ベース**に変更（6月1日〜）。無制限サブスクリプションからAIクレジット制へ移行し、コスト管理が重視されています。MicrosoftはCopilot Studioのエージェント機能も強化中です。
