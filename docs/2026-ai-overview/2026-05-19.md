**本日のAI関連ニュースまとめ（2026年5月19日時点、過去2日以内の情報中心）**

### OpenAI / ChatGPT / Codex関連
OpenAIがDell Technologiesと提携し、**Codex**（AIコーディングエージェント）を企業向けハイブリッド/オンプレミス環境で展開可能に。コードレビュー、テスト、インシデント対応、大規模リポジトリ解析などで利用され、週400万人以上の開発者が活用中。企業データセキュリティを重視した動きとして注目されています。

[@OpenAIDevs](https://x.com/OpenAIDevs) や [@sama](https://x.com/sama) 周辺でも企業展開の議論が活発です。

### Claude / Anthropic関連
**Claude Opus**に「Fast mode」が追加され、応答速度が約2.5倍に（品質維持）。ただしトークンコストは通常の約6倍（入力$30/出力$150 per 1M tokens）。ライブデバッグや急ぎのコード修正に有効で、「/fast」コマンドで即時有効化可能。

[@tetumemo](https://x.com/tetumemo/status/2056585616020947000) が詳細図解・検証を投稿し、「鬼モードだがコストが高い」と実践的評価を共有。Claude Codeユーザーからも「締め切り前活用」の声が上がっています。他のClaude関連アカウント（@ClaudeDevsなど）でも同様の話題。

また、Claude Mythos Previewを使ったmacOS M5チップのセキュリティ突破事例（11年越しの課題解決）も話題に。

### Google / Gemini / Pixel関連
**Gemini**の使用制限を「compute-based」（プロンプト複雑度・機能・チャット長考慮）に変更。5時間ごとにリフレッシュされ、週上限あり。GitHub Copilotに似た柔軟アプローチで、重いタスクも扱いやすくなりました。

Pixel 10シリーズのAI機能（Magic Cue、Gemini Live統合、カメラAIなど）が継続的に議論され、Tensor G5チップのオンデバイス処理が強みとして挙げられています。Google I/O関連のGeminiアップデート（UI刷新、Flashモデルなど）も言及。

[@GoogleAIStudio](https://x.com/GoogleAIStudio) や [@osanseviero](https://x.com/osanseviero) 周辺でGemini実践例が共有されています。

### xAI / Grok関連
xAIが**Grok Build**（初のAIコーディングエージェント）をSuperGrok Heavyサブスクライバー向け早期ベータ公開。ターミナルから動作し、Claude CodeやOpenAI Codexに対抗。フィードバック募集中で、将来的に競争激化が見込まれます。

[@grok](https://x.com/grok) や [@The_AGI_WAY](https://x.com/The_AGI_WAY) などで新機能の言及あり。Grokのスキル拡張（web/iOS/Android、ドキュメント生成）も進行中。

### その他のモデル・ツール
- **DeepSeek**や**Qwen**：トラフィックシェアでGrokを上回る動きが継続（Geminiがシェア4分の1を維持、Claude急伸）。オープンソース系中国モデルが効率性で注目。
- **Perplexity**：リアルタイム検索強みで比較議論多し。
- **Meta Llama**：エコシステム拡大中だが、具体的新発表は本日控えめ。
- AIエディタ/CLI：Claude CodeやCodexのプロジェクト連携事例が増加（VS Code拡張など）。Genspark/DIAなどのAIブラウザ関連も実践共有あり。

### 市場・その他動向
