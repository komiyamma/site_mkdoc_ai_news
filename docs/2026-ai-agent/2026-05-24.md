**過去1週間（2026年5月17日〜24日頃）のAI Agent関連動向まとめ（指定ツール中心）**

### Claude Code (Anthropic)
Claude Codeは引き続きユーザーから高評価で、日常的なvibe codingやモバイル連携、プラグイン開発での活用が目立つ。複数のユーザーが「革命的」と表現し、Telegram連携で外出先からコード作業するケースや、MCPプラグイン（AMC Theatres、Luma Events、iMessage bridge、社会自動化など）構築事例が共有された。

- **@WheelieInvestor**はClaude Codeの速度に不満を持ち、Hermes agentとCodexへ移行したと報告。基本的なコーディング知識はあるが、ほとんどの作業をagentに任せている。
- **@Nataliebru1**はClaude CodeをBitcoin以来の革命と絶賛し、Telegram連携で外出中にvibe codingを楽しむ体験を語った。
- プラグイン開発では**@_itsjustshubh**がClaude Sonnet + カスタムMCPサーバーでカレンダー連動のソーシャル自動化ツールを作成した事例を挙げ、複数のスキル構築を報告。

ウェブ上でもClaude CodeのCLI Agent活用（VS Code連携、Go開発、グローバルAI Agent構築）に関するチュートリアル動画が活発に共有され、CLIツールのトークン効率性や再利用可能なスキル構築が強調された。

### Codex CLI (OpenAI)
Codex CLIは速度やコンパクション機能の不具合報告があった一方、新機能「Appshots」（MacでCommand+Command二回押しでアプリ窓内容を丸ごと渡す）が便利と好評。Claude Codeとの協調プロトコル構築も話題に。

- **@giulio_leone97**が複数回、Codexアプリ/CLIのコンパクション機能破損を指摘し、即時ホットフィックスを求め、トークン浪費を問題視した。
- **@tigertigerhan**はAppshots機能を紹介し、画面内容を簡単にCodexへ渡せる点を大絶賛。
- **@garudafooddeli**はCodexとClaude Codeを協調させ、AGENTS.mdやCLAUDE.mdでプロトコル作成を楽しんでいると投稿。お互いの得意分野を活かしたワークフローを模索。

ウェブ比較ではCodex CLI（Rust製、オープンソース）がローカルサンドボックス実行やクラウドPR生成で強みを発揮し、Claude Codeと並んでagentic codingの代表格として扱われた。

### Gemini CLI (Google) / Antigravity CLI
Gemini CLIがAntigravity CLIへリネームされた動きが話題。Googleの多モデル対応や高速性が評価される一方、Claude Codeとの比較でトークン消費やパフォーマンス差が議論された。

- **@ravsau**はGemini CLI→Antigravityリネームを「良い動き」と評価。ブランドが非Geminiモデルも含められる点に言及。
- **@naruton999**はantigravity-cliへ移行し、Swift未経験アプリ機能追加をagentに任せて勉強中と報告。
- **@sorare_crypto**は「Claude > Gemini CLI」とシンプル比較。

ウェブではGemini CLI vs Claude Codeの比較記事や、Antigravity CLIのagenticワークフロー（ターミナル/ブラウザ連携、マルチエージェント）が紹介され、Google CloudのAgent Platformとの統合も進んでいる。

### GitHub Copilot (Agent Mode)
Agent Modeの自動編集・テスト実行・エラー修正機能が「仕事量を大幅削減」と評価される一方、中途半端との声も。Copilot CLIチュートリアルやEclipse版オープンソース化が共有された。

- **@ai_kuraberu**はAgent Modeを従来の補完型から「複数ファイル自動編集・テスト自動実行」へ進化したと説明し、生産性向上を強調。
- **@takuya_stmn**は「中途半端」と率直に指摘。
- **@ikumi_shikaku**はCopilot for Eclipseオープンソース化で、チャット/補完/Agent mode/Skills/MCP連携の内部構造を学べると紹介。
