**過去1週間（2026年5月10日〜17日頃）のAI Agent関連の主な動き**を、指定ツールを中心にまとめます。主にCLIベースのagentic codingツールの比較・統合・実利用事例、GitHub CopilotのAgent Mode進化が活発です。古い情報は除外し、詳細がわかるものを優先して抽出。

### Claude Code (Anthropic)
Claude Codeは複雑なコードベースや長期的リファクタリングに強く、Plan Modeを使ったagent構築や並列実行の事例が目立つ。ユーザーはデータ収集・整形・SQL生成などのタスクをエージェントに任せ、自分は最小限の確認のみという「理想的な休暇中ワークフロー」を報告。

- 複数のagent（Claude Code + Codexなど）を組み合わせたセットアップが人気。Hermes Agentをコーディネーターに、Claude Codeをcoding specialistとしてsubprocessで呼び出し、 bounded taskを処理させる例。ClaudeのMaxサブスクリプションを活用し、Hermesが結果を検証。
- 環境変数`CLAUDE_CODE_ATTRIBUTION_HEADER=0`でattribution header（計費関連）を無効化するTipsも共有された。
- ドキュメントの質に対する率直なフィードバック（「ドキュメントがクソ」と指摘される）も日常的に見られるが、全体として生産性向上ツールとしての評価は高い。

Parallel CodeなどのツールでClaude Codeを他のagentと同時並行実行するハーネスも活発に議論。

### Codex CLI (OpenAI)
Codex CLIはバックエンド性能が高く、クラウドサンドボックス実行やTUIが特徴。Claude Codeとの組み合わせで「最強スタック」として言及されることが多い。

- ベンチマークではCodexが全体スコア最高（67.7%）を記録。特にバックエンド性能で優位（58.5%）。Claude Codeはフロントエンド95%と高いがバックエンド38.6%で総合55.5%と差がつく。
- ワークスペースオペレーターとしての実演例：CMUX docsを読み、CLIを理解し、ターミナルペインを自然言語で制御（Geminiを別ペインで起動など）。autocompleteを超えた自律的操作が注目。
- mco-org/mcoのようなオーケストレーションツールでCodex CLIをClaude Code、Gemini CLIなどと並行 dispatchし、コンセンサスを合成する動き。

### Gemini CLI (Google)
Googleのターミナルagentとしてリポジトリ作業・研究に強い。オープンソースで無料枠あり（1,000 requests/day程度の言及）。

- Entire CLIやmcoなどのツールがGemini CLIをネイティブサポート。gitワークフローにagentセッションをキャプチャ。
- Cloud WorkstationsでAI agent-assisted codingとして公式統合。
- 他のCLIツールとの比較でUI生成の速さやReActループが評価される一方、全体的なagentic深さではClaude/Codexに劣るとの声も。

### GitHub Copilot (Agent Mode)
Agent Mode / Cloud Agentの機能強化が続き、IDE内自律編集・ターミナル実行・反復修正が現実的に使える段階に。

- VS Code/JetBrainsでAgent ModeがGA。マルチファイル編集、terminal command実行、エラー反復が可能。Cloud AgentはGitHub Actions環境でissueベースの自律タスク実行。
- REST APIでCopilot Cloud Agentタスクを開始/制御可能に（Business/Enterpriseプラン）。
- ServiceNow Build AgentがCopilot（およびClaude Codeなど）に統合。開発者が使っているIDE内でプラットフォーム機能を提供する戦略。
- Planning Modeの改善要望（実行詳細の不足、プラン版管理、clarification質問）も出ている。

### Qwen Code (Alibaba)
言及は比較的少ないが、無料APIアクセスが強みとしてmcoオーケストレーターなどでClaude/Codex/Gemini/OpenCodeと並んでサポート。完全無料の代替として位置づけられる。

### 全体のトレンド
- **オーケストレーション/並行実行**：mco、Parallel Code、Entireなどのツールで複数agent（Claude Code + Codex + Gemini CLI + Qwen Code）をチーム化し、1つのpromptで分散処理→レビュー→合成する流れが加速。
- **統合ツール**：gitワークフローへのagentセッション記録、任意agent対応のハーネスが増加。
- **実利用**：学生・開発者層での採用はまだ10%程度と低いが、使用者は「世界的に先行している」との認識。データ処理自動化や科学agentスキル（K-Dense-AI）との組み合わせも登場。
