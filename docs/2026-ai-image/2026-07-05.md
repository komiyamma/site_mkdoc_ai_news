**過去一週間（2025年6月末〜2025年7月5日頃）のAI画像生成サービス（Google NanoBanana系・Adobe Firefly除く）の主な話題まとめ。**

X（Twitter）やウェブ上の最近の発言・情報から、**Grok（xAI）の画像生成**と**ChatGPT（OpenAI）の画像生成**を中心に活発な議論が見られました。他の有力サービス（Midjourney、Flux系、Stable Diffusionなど）も言及されますが、過去一週間の新鮮な具体的な更新報告は限定的でした。GitHub関連では目立った新リポジトリや大規模公開情報は確認されませんでした（主に既存ツールの利用報告）。

### Grok（xAI）の画像生成（Grok Imagine / Flux系）
Grokの画像生成機能（Imagine）が日常的に使われており、**SuperGrokユーザー向けのクォータ制限**に関する不満や活用例が複数見られます。xAIの公式更新として、API関連の改善（画像・動画生成のBatch API強化、ファイル統合など）が最近報じられていますが、過去一週間の大規模新機能発表ではなく継続的な利用報告が中心です。

- **クォータ制限の話題**: SuperGrokの画像生成制限（週50回程度？）が厳しく、サービス解約を検討する声が出ています。[@grok](https://x.com/grok)自身が「Imagineがクォータを多く消費する」「追加クレジット購入やHeavyプランを」と説明するやり取りが複数ありました。
- **活用例**: ユーザー生成画像（花火、キャラクターなど）が共有され、楽しまれている様子。例: 「Mars fireworks for the 250th? This is pure magic. 🚀🎆 Grok Image is buzzing...」と[@grok](https://x.com/grok)が反応する投稿。

Grok Imagineは**自然言語編集やスタイル制御**が強みとして引き続き評価されており、Flux.1系モデルとの連携でテキスト描写や創造性が話題に上りますが、過去一週間は制限関連のリアルユーザー声が目立ちました。

### ChatGPT / GPT Image系（OpenAI）
ChatGPT内の画像生成（ChatGPT Images 2.0 / GPT-image系）が**テキスト描写の精度向上や会話型編集**で好評。DALL-E後継としてプロンプト理解・一貫性・編集機能が強化されており、日常業務やクリエイティブで活用報告が増えています。

- **具体的な活用**: プロンプトで複雑なシーン生成やキャラクター一貫性、ストーリーボード作成が可能。ユーザー例として、America 250祝賀プロンプトでChatGPTを使い、複数キャラクター統合画像を作成した報告（コピー問題は指摘ありつつ良好）。[@TyrakAeternus](https://x.com/TyrakAeternus/status/2073616594870169832)（詳細プロンプト共有）。
- **利便性**: 「mockup from chatgpt but I need to vectorize」など、日常デザインでの利用声。Codexとの画像生成差異指摘も。

過去一週間のXでは、**精度向上による実務代替可能性**（インフォグラフィック、広告など）が実感として共有され、Photoshop代替としての期待が高まっています。

### その他の有力AI画像生成サービス
- **Midjourney**: 芸術的描写・構図の美しさが再確認されるが、過去一週間は具体的新アップデート報告は少なく、既存ユーザーによる「光と影・衣装の芸術レベル」評価が散見。
- **Flux / Stable Diffusion / Leonardoなど**: Flux Kontextなどの活用例（ぬいぐるみ取り込みなど）が見られ、オープンソース系のカスタム利用が継続。Anifusionのような漫画特化ツールのアップデート（AI編集・漫画風加工）も関連話題。
- **全体傾向**: オールインワンプラットフォーム（GlobalGPTなど）やOne-shot Character Model（1枚画像からのトレーニング）のような効率化ツールが注目され、商用・クリエイティブ両面で多様な選択肢が議論されています。

**まとめ**: 過去一週間は**Grokの利用制限実感**と**ChatGPT Imagesの精度・編集利便性**がX上で活発に語られ、大手サービスの成熟期を感じさせる内容でした。新規大規模リリースより、日常活用・制限・ワークフロー改善の声が中心。GitHubでは新プロジェクトの目立った動きはなく、既存モデルのAPI/ツール活用が主流のようです。情報は変動しやすいので、最新は各公式アカウントやAPIドキュメントで確認してください。
