**過去24時間（2026年7月3日〜4日頃）のGoogle「Veo 3」および「Google Omni」（Gemini Omni / Omni Flash）に関する主な情報は以下の通りです。** 主にGemini API経由の動画生成機能「Gemini Omni Flash」の展開や利用事例が活発で、Veo 3.1シリーズ（ネイティブ音声対応、高品質動画生成）と連携したマルチモーダル機能として注目されています。古い情報（数日前以前のリリース発表など）は除外し、最近の投稿・議論を中心にまとめます。

### Gemini Omni Flash（Omni関連）の主な動き
- **Gemini API / AI Studioでの動画生成・編集機能が利用可能**：テキストプロンプトからの高品質動画生成、既存動画の編集（inpainting、スタイル転送、拡張）、画像-to-動画などがサポート。Nano Banana 2 Lite（高速画像モデル）と同時にリリースされ、開発者向けに価格競争力が高い点が評価されています。例: 1K画像生成後、10秒動画を約$0.10/secで作成可能。
- 具体的な利用例として、**@shontan**さんが実写人物画像から動画生成をテスト。「Sora2の代わりを探す旅」として、キャラクター「ナオキ」くんのソフトクリーム作成動画や変身動画を作成。Omni Flashは日本語プロンプト対応も良く、不安定だったキャラクターを動かせたと詳細に報告。サンバイザー姿が似合うなどビジュアルのクオリティを称賛。
- **@TeksCreate**さんはDeepMindのリリースを引用し、API経由のネイティブ動画生成/編集の意義を解説。開発者インフラとしての位置づけを強調し、RunwayやPikaに対する価格優位性を指摘。
- **@hqmank**さんはGoogle AI Studioでの試用を推奨。画像生成から動画化、照明変更や製品スワップなどの編集例を紹介。

### Veo 3 / Veo 3.1関連
- Veo 3.1（& Fast/Lite変種）はAI Studioでテキスト/画像/動画入力に対応し、720p〜4K、ネイティブ音声ペアリング、高現実性（光影・物理演算）が特徴。APIサンプルコードも公開されており、開発者利用が進んでいます。
